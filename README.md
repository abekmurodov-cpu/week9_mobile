# cart_four_ways

Lab 9 — *One Cart, Four Ways*: the same shopping cart built with `setState`,
Riverpod (`Notifier`), a `Cubit` and a `Bloc`, sharing one model (`lib/models`),
one fake API (`lib/services`) and one dumb UI (`lib/widgets`).

```sh
flutter pub get
flutter run        # home page → four cart pages
flutter test       # 9 tests
```

Answers, logs and the comparison table are in [NOTES.md](NOTES.md).
Git tags `p1-shared` … `p5-bloc` mark the end of each part.
